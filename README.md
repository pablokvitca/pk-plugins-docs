# PK Plugins docs

Documentation for my [Obsidian](https://obsidian.md) plugins, one folder per plugin. Currently:

- [Note Narrator](https://github.com/pablokvitca/note-narrator): reads notes aloud with text to speech.

This repository is an **Obsidian vault**. Open the folder as a vault in Obsidian to edit it. It is published with Obsidian Publish.

- Start at `index.md`, the home page for all plugins.
- Each plugin has its own folder with its home page (for Note Narrator: `Note Narrator/Note Narrator.md`).
- Conventions, publishing steps and the screenshot checklist are in `Meta/` (not published).
- A plugin's screenshots go in its own `Screenshots/` folder.
- Issues and pull requests are closed here. Report problems on the plugin's own repository.

| Folder | Contents |
| --- | --- |
| `Note Narrator/` | Everything for the Note Narrator plugin |
| `Note Narrator/Getting Started/` | Installation, quick start, and setting up each provider's key |
| `Note Narrator/Using Note Narrator/` | The panel, reading, playback, saving, highlighting, background jobs, commands |
| `Note Narrator/Settings/` | One page per settings group |
| `Note Narrator/Reference/` | Frontmatter properties, supported platforms, limitations, privacy, troubleshooting |
| `Note Narrator/Roadmap/` | Shipped, in progress and planned work |
| `Meta/` | Authoring notes and screenshot checklist (shared) |
